# Cinnaroids

[Install the WASM component](install.md) using Cinnabar's Mods screen, then press **F7** to open its panel. [Module controls and behavior](modules.md).

Click a slider's number to type a value; **Enter** applies it and **Escape** cancels. Click a **Keybind** keycap and press a keyboard key to change that module's binding. The menu key is reserved. Panel preferences persist, while gameplay modules start disabled for each new component instance.

Disable or reload Cinnaroids through **Settings → Mods**. Cinnabar manages it directly; there is no launcher to keep running.
