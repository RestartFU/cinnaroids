# Cinnaroids

[Install the WASM component](install.md) using Cinnabar's Mods screen, then press **F7** to open its panel. [Module controls and behavior](modules.md).

Click a slider's number to type a value; **Enter** applies it and **Escape** cancels. Click a **Keybind** keycap and press a keyboard key to change that module's binding. The menu key is reserved. Panel preferences and gameplay module switches persist across reloads and restarts. Modules with missing required permissions remain off.

Press the menu key again to close the panel. While capturing a keybind or editing a number, keyboard input belongs to that editor and does not toggle the panel or modules.
The menu stays available when optional gameplay permissions are declined.

Disable or reload Cinnaroids through **Settings → Mods**. Cinnabar manages it directly; there is no launcher to keep running.
