Cinnaroids 2.0.0 — Windows x64
Validation snapshot: 2026-10-04

Rust GPUI launcher with embedded Rust WASM modules. The launcher installs
the component and starts its compatible Cinnabar host; runtime controls
are managed in the in-game panel. No operating-system input hooks remain.

Completed local checks:
- 9 launcher tests: migration, client selection, component installation,
  explicit child grants, and preserving preferences after launcher drop.
- 28 guest tests: independent module switches, click timing, aim selection,
  reach, settings normalization, emergency stop, and key capture lifecycle.
- 42 host tests: capability denial, transactional commit, trap quarantine,
  reload, bounded controls, and coalesced asynchronous settings persistence.
- 24 focused app adapter test results were passing; two fixture-dependent
  paths reported named skips. Covered input ownership, cursor restoration,
  attack edges, reach admission, and preserving wall occlusion.
- 13 panel/schema tests: validation, grouped cards and category tabs,
  pointer controls, feedback, and panel layout reuse.
- 6 font catalog tests plus the private alias lifecycle regression passed.
  Three real Inter Medium fixture tests verified antialiased glyphs,
  transparent spaces, an isolated private atlas page, and identical logical
  layout at 1x/2x raster densities. A sampling regression confirms only
  private outline text uses filtering; default fonts retain nearest sampling.
- The real packaged WASM component passed a host execution probe within
  the 100,000-fuel callback budget, with no WASI imports.

Upstream PR #88 was squash-merged into dev at 7da8eac26deccbd0205059c1abecbe7a4702d2b0.
All six required CI jobs passed on the reviewed PR head 38582109.
The module SDK and packaged host use that merged dev commit.

Native GPU previews were inspected at 1280x720/GUI 2 and 2559x1439/GUI 3
in dark mode, plus 1920x1080/GUI 4 in light mode, DPI 1. Compact cards,
sharp text, clipping, layering, and colors passed inspection. Live tabs,
slider feedback, and toggle input worked at 2559x1439. Escape closing
passed earlier native checks. The README uses the original dark 1280x720
GPU capture; its source and hash are recorded in assets/PROVENANCE.txt.

Native physical Right Shift input remains unverified: the automation
tool's Shift_R request produced ShiftLeft. No successful native Right
Shift test is claimed. The panel is configured for the ShiftRight key.
Connected multiplayer behavior and server acceptance have not been tested.
