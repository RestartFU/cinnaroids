# Cinnabar clicker

Minimal Windows clicker and Cinnabar player aim assist, built with Rust + GPUI.

![Cinnabar clicker](assets/screenshot.png)

**F8** toggle · Hold left mouse to click · **F10** stop.

Aim assist has adjustable strength and Continuous / While clicking modes. Use **Start Cinnabar** in the Aim assist tab with a compatible mod-enabled runtime.

Build with Rust and Visual Studio C++ Build Tools: `cargo run --release --locked`. [Aim assist setup](docs/aimassist.md).
