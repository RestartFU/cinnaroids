# Cinnaroids

Clicker, player aim assist, and reach for Cinnabar, controlled in-game with **Right Shift**.

![Cinnaroids](assets/screenshot.png)

Open **Cinnaroids.exe** while your installed Cinnabar is running. It attaches automatically; press **Right Shift** to manage modules. **F10** stops all modules.

Rust + GPUI launcher and a WASM module. Build: `cargo run --release --locked`. [Setup](docs/modules.md).
